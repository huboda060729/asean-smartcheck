# ASEAN SmartCheck GitHub Pages

Static browser-only build of the ASEAN SmartCheck infectious disease risk screening and stratified warning demo.

## Features

- Browser-side interpretable risk scoring
- Suspected pathogen ranking
- Infection stage and time-window estimation
- Severity assessment and four-level warning
- Evidence chain, recommendations, and human-review safeguards
- No Python server required after publication

## GitHub Pages

The site is served from the `docs/` directory. All calculations run locally in the browser and no personal input is uploaded.

## Safety

This project is a research and teaching prototype. It does not provide a medical diagnosis and must not replace professional clinical or public-health judgment.
